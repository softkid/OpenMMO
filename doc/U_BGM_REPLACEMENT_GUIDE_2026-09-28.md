## 🛠️ 3. 음악 파일 교체 방법 안내

### 1) 오디오 파일 저장 위치
* **경로**: `client/public/audio/bgm/`
* 새로운 MP3 또는 M4A/OGG 음원 파일을 위의 경로에 업로드하시면 됩니다.

### 2) 곡 메타데이터 업데이트 (선택 사항)
새로운 곡명 및 파일명으로 교체할 경우 `data-src/bgm.csv` 파일에서 목록을 수정할 수 있습니다:
```csv
id,file,seconds
HAHAO Theme,hahaoworld_theme.mp3,210
```

수정 후 `git push`를 진행하시면 서버에 자동으로 반영되어 새로운 배경음악이 재생됩니다!
